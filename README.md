# ABACUSLAB 科学计算智能体宣传片

- 成片：`ABACUSLAB_60s_1080p.mp4`
- 规格：60 秒，1920 × 1080，16:9，30 fps，H.264 / AAC。
- 内容：开场提问、工作流、模板库、自然语言提问、平台实录、结论与局限、MSD 图表、功能总览、品牌片尾。
- 画面素材：用户提供的 4 张截图与约 10 秒平台录屏，原文件保持不变。
- 动效：截图横移、文字输入、区域重点展示、原始曲线逐步揭示、淡化转场。
- 配音：中文合成女声，按分镜分段生成并对齐。
- 音乐：脚本合成的轻电子背景音乐与提示音，无外部商用歌曲。
- 科学信息：使用原图中的 300 K / 1600 K MSD 曲线；保留“示例对比不等于精确熔点”以及后续验证建议。

`subtitles.srt` 为字幕文件，成片已内嵌可见字幕。`storyboard.jpg` 为分镜预览，`verification.json` 为输出文件检查结果。

可修改源文件：`render_video.py`（画面与字幕）、`timeline.json`（旁白）、`make_voice.py`（语音）、`finish_audio.py`（音乐与混音）。
